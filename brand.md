# Brand — Bidden

_Status: deferred_

The user chose to keep the existing palette rather than run a formal brand pass. This
project uses a dark terminal-derived system defined in `swarm/web/tailwind.config.ts`:

| Token    | Value     | Role |
|----------|-----------|------|
| `ink`    | `#07090d` | page ground |
| `panel`  | `#0e1219` | card surface |
| `edge`   | `#1c2431` | borders, rules |
| `dim`    | `#5d6b7f` | secondary text |
| `pale`   | `#9fb0c6` | primary text |
| `accent` | `#4ade80` | live / winning / settled |
| `warn`   | `#fbbf24` | awaiting, mock badge |
| `hot`    | `#f472b6` | price movement, reputation |

Type is monospace throughout, deliberately: this is infrastructure tooling and the numbers
are the product. Voice is measured and specific, never promotional. Numbers on screen are
measured values, never estimates.

To set up a real brand palette, typography, and voice at any time, run:

    /brand-design

or say: "pick brand colors"
